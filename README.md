# minigame-1
## Devlog
The components are essentially the tweaks and fine tuning that make up a gameobject. So something like a player character would have a collider or a walking/running state script. The scene is essentially the sandbox or area where you interact with these gameobjects and other overall systems. So I suppose I could compare it to film. The actors and even props are all gameobjects, and the things they do for a scene need to be set up with components, like their wardrobe or their lines in the script. And the scene itself would be the set, where all the actors and props are put together.
